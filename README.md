# LAG3 ubiquitination — single-cell and TCGA analysis code

Analysis code for the computational figures in:

> **Ligand-induced ubiquitination unleashes LAG3 immune checkpoint function by
> hindering membrane sequestration of signaling motifs**
> *Cell* (2025), published online 17 March 2025.
> doi:[10.1016/j.cell.2025.02.014](https://doi.org/10.1016/j.cell.2025.02.014)

This repository covers the human single-cell RNA-seq and TCGA survival analyses
only (**Figures 7G–7L and Figure S8**). The molecular, biochemical and imaging
experiments reported in the paper are not computational and have no code here.

---

## What the analysis does

CD8<sup>+</sup> tumour-infiltrating lymphocytes (TILs) from a relatlimab
(anti-LAG3) clinical trial cohort were re-analysed to ask whether *LAG3* and the
E3 ligases *CBL* / *CBLB* are co-regulated in exhausted T cells, and whether
their co-expression tracks with patient outcome and response to LAG3 blockade.

- LAG3 and CBL module scores are projected onto annotated CD8<sup>+</sup> TIL clusters.
- Patients are stratified into LAG3<sup>Low</sup>, LAG3<sup>+</sup>Cbl<sup>Low</sup>
  and LAG3<sup>+</sup>Cbl<sup>High</sup> groups.
- Group membership is related to TOX expression, functional-cluster composition
  before and after relatlimab, pathway enrichment, and overall survival in
  TCGA-SKCM melanoma.

## Repository layout

```
1.Data/     input data (not distributed — see "Data availability")
2.Script/   analysis scripts, numbered in execution order
3.Output/   figures and tables produced by the scripts (not distributed)
```

Scripts expect the **repository root** as the R working directory, e.g.

```r
setwd("/path/to/lag3-ubiquitination")
source("2.Script/01_data_prep.R")
```

Every script carries a header stating its figure panel, its inputs and outputs,
the upstream script it depends on, and its original filename in the lab archive.

## Data availability

**No sequencing data or intermediate objects are included in this repository.**
All inputs are public and must be downloaded before running the scripts:

| Dataset | Source | Used by |
| --- | --- | --- |
| CD8<sup>+</sup> / CD4<sup>+</sup> TIL scRNA-seq (relatlimab trial, NCT03743766) | GEO [**GSE225063**](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE225063) | `01`–`04`, `06`–`09` |
| TCGA-SKCM expression and clinical data | [GDC Data Portal](https://portal.gdc.cancer.gov/projects/TCGA-SKCM), retrieved with the `easyTCGA` R package | `05` |

Download the processed Seurat object from GSE225063 into `1.Data/` and set
`INPUT_OBJ` at the top of `01_data_prep.R` to its filename. The intermediate
objects the scripts write to `1.Data/` and the figures they write to `3.Output/`
are regenerated by running the pipeline; they are deliberately not tracked here.

The one data file that *is* included,
[`1.Data/Relevant_CD8_Pathways_with_Detailed_Categories.csv`](1.Data/Relevant_CD8_Pathways_with_Detailed_Categories.csv),
is a manually curated pathway-to-category table used to group pathways in
Figure S8. It encodes a curation decision that cannot be regenerated
automatically, so it ships with the code.

The scRNA-seq data were originally published in Cillo *et al.*,
*Cell* **187**, 4373–4388 (2024), and are re-analysed here.
